# Hunar-ai-assingnments

This repository contains the Full Stack web application built for the Hunar AI assignment.

## Tech Stack
- **Frontend**: Next.js, Tailwind CSS (v4), shadcn/ui, Lucide Icons
- **Backend**: Python, FastAPI, SQLAlchemy (Async), SQLite/PostgreSQL
- **Voice AI**: Hunar Voice AI APIs

## Features
1. **AI Hiring Assistant**: Create voice AI screening calls.
2. **People Search & Reachout**: Search for candidates and run bulk outbound voice campaigns.
3. **Attendance AI**: Concept page explaining a smartphone-free IVRS + Voice AI attendance system.
